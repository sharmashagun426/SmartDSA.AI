## 🌟 About SmartDSA.AI

**SmartDSA.AI** is an AI-powered Data Structures and Algorithms instructor designed to help developers, students, and coding enthusiasts improve their problem-solving skills.

Whether you are preparing for:

- 💼 FAANG Interviews
- 🏆 Competitive Programming
- 🎓 DSA Learning
- 👨‍💻 Software Engineering Roles

SmartDSA provides step-by-step explanations, optimized approaches, complexity analysis, and coding guidance.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/sharmashagun426/AI-DSA_Instructor.git
```

## Install Dependencies

```bash
npm install
```

## Environment Setup

Create `.env` file:

```
GEMINI_API_KEY=your_api_key_here
```

## Run Application

```bash
npm start
```

Application will start:

```
http://localhost:3000
```
